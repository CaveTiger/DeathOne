# Character XML 메모

## 기본 정보
- [ ] `ID` 중복 없음
- [ ] `Label`, `Description` 작성
- [ ] `Rarity`, `Pattern` 의도대로 설정

## 스탯 검토
- [ ] `Hp`, `Atk`, `Def`, `Speed` 범위 확인
- [ ] `Evasionrate`, `Accuracy` 범위 확인 (0.0~1.0 권장)
- [ ] 테스트용 과한 수치라면 주석으로 명시

## 스킬 검토
- [ ] `Skills` 4칸 구성 확인
- [ ] 각 스킬 ID가 실제 데이터에 존재
- [ ] 컨셉과 스킬 조합이 일치

## 패시브 검토
- [ ] `Passives` ID가 실제 `BasePassive.xml`에 존재
- [ ] 면역/특수 패시브 조건 확인 (예: 상태이상 면역 ID)
- [ ] 테스트용 패시브는 주석으로 표시

## 리소스 경로
- [ ] `Sprite` 경로 존재 확인
- [ ] 전투 시작 시 `Stand` 스프라이트 정상 로드 확인

## 전투 동작 체크
- [ ] 턴 진입/행동/종료 정상
- [ ] 버프/디버프 타겟이 의도대로 적용
- [ ] 상태이상 면역/중첩 규칙이 의도대로 적용

- 강점 1줄:
- 약점 1줄:
